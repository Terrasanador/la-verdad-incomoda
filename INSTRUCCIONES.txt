CORRECCIONES INCLUIDAS
- HTTP 429 ya no produce credibilidad 0% ni 50%.
- En acceso bloqueado, credibilidad y confianza se devuelven como null.
- Se agrega estado_tecnico: HTTP_429, ACCESO_RESTRINGIDO u OK.
- Se agregan acciones_disponibles: reintentar, subir captura o pegar texto.
- Se evita confundir una explicación generada con contenido realmente recuperado.
- Se respeta Retry-After cuando el límite proviene de la API de OpenAI.
