PAQUETE SEO Y SEGURIDAD PARA VERCEL — LA VERDAD INCÓMODA

1. En GitHub abre el repositorio conectado a Vercel.
2. Sube estos archivos a la RAÍZ del repositorio.
3. Sustituye el index.html actual por el index.html de este paquete.
4. Sustituye robots.txt y sitemap.xml si GitHub pregunta.
5. Conserva sin cambios tus archivos de API, package.json y demás archivos existentes.
6. Confirma el commit. Vercel desplegará automáticamente.
7. Cuando Vercel muestre “Ready”, abre https://www.laverdadincomoda.mx/ y prueba una consulta.
8. En Search Console, inspecciona https://www.laverdadincomoda.mx/ y pulsa “Solicitar indexación” únicamente si Google muestra una versión anterior.

IMPORTANTE: no borres api/analyze.js, api/health.js, package.json ni la variable OPENAI_API_KEY.
