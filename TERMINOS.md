# Términos de uso — borrador inicial

La Verdad Incómoda es una herramienta de apoyo para investigar afirmaciones mediante inteligencia artificial, búsqueda web y fuentes públicas.

Los resultados pueden contener errores u omisiones. No constituyen asesoría médica, jurídica, financiera, científica, electoral ni profesional. El usuario debe revisar las fuentes y acudir a especialistas cuando una decisión pueda producir consecuencias importantes.

Está prohibido utilizar el servicio para:

- acosar, difamar o perseguir personas;
- publicar datos personales sin autorización;
- presentar un análisis automatizado como sentencia oficial;
- abusar de la API o intentar obtener la clave privada;
- enviar material ilícito o sin autorización.

Las conclusiones pueden actualizarse cuando aparezca nueva evidencia.

Este documento es un borrador inicial y requiere revisión jurídica antes de un lanzamiento comercial.
