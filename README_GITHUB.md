# La Verdad Incómoda

## ¿Cómo funciona?

La Verdad Incómoda utiliza inteligencia artificial, búsqueda web y contraste de evidencia para verificar afirmaciones.

Puedes:
- Pegar un enlace.
- Subir una imagen.
- Adjuntar un documento.
- **Copiar y pegar directamente el texto o la noticia que deseas verificar. No es necesario un enlace.**

La IA identifica la afirmación, extrae texto cuando es necesario, busca evidencia, contrasta fuentes y genera un informe con:
- Veredicto final.
- Clasificación técnica.
- Credibilidad.
- Confianza.
- Resumen.
- Hechos comprobados.
- Evidencia.
- Contexto.
- Fuentes consultadas.
