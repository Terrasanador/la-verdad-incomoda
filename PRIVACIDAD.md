# Política de privacidad — borrador inicial

La Verdad Incómoda procesa las consultas, textos, enlaces e imágenes que el usuario envía con el fin de realizar una investigación. El servicio puede transmitir ese contenido a proveedores tecnológicos necesarios para ofrecer la función, incluido OpenAI.

No se debe enviar información personal sensible, secretos profesionales, expedientes privados ni material para el que no se cuente con autorización.

El responsable del sitio deberá completar antes del lanzamiento definitivo:

- nombre o razón social responsable;
- correo de contacto;
- datos concretos que se conservan;
- plazo de conservación;
- servicios de analítica utilizados;
- fundamento y procedimiento para derechos de acceso, rectificación, cancelación u oposición;
- jurisdicción aplicable.

Este documento es una base informativa y requiere revisión jurídica conforme al país y modelo de operación del proyecto.
