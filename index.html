¿Cómo funciona?

La Verdad Incómoda usa inteligencia artificial, búsqueda web y contraste de evidencia pública para analizar afirmaciones y explicar cómo llegó a cada conclusión.

🔗 Pega el enlace de una noticia, publicación, video o red social.
📷 Sube una imagen o captura de pantalla con texto visible.
📄 Adjunta un documento compatible.
📝 También puedes copiar y pegar el texto o la noticia que quieres verificar. No necesitas un enlace.
  1. Identifica la afirmación principal.
  2. Lee el texto visible de imágenes y documentos.
  3. Busca documentos, registros y fuentes públicas.
  4. Contrasta evidencia favorable, desfavorable y limitaciones.
  5. Entrega un veredicto, porcentajes, contexto y fuentes consultadas.
